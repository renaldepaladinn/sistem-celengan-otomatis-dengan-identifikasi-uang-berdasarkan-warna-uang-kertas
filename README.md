## Sistem Celengan Otomatis dengan Identifikasi Uang Berdasarkan Warna Uang Kertas
Proyek pendeteksi nominal uang kertas berbasis Arduino UNO yang menggunakan sensor warna untuk membaca pantulan cahaya dari uang kertas. Sistem mengolah sinyal sensor menjadi nilai RGB untuk mengenali warna uang berdasarkan data referensi, kemudian menampilkan nominal uang yang terdeteksi dan total tabungan melalui LCD 16x2.

## Fitur
  •	Deteksi warna uang kertas menggunakan sensor warna.
  
  •	Pengolahan data RGB untuk mengenali nominal uang.
  
  •	Tampilan nominal uang yang terdeteksi melalui LCD.
  
  •	Penghitungan total tabungan secara langsung.

## Teknologi
  •	Mikrokontroler: Arduino UNO
  
  •	Bahasa Pemrograman: C++ (Arduino framework)
